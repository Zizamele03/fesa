# Fesa

Fesa is an AI-powered job application assistant that helps job seekers
tailor their resumes and cover letters to specific job opportunities.

## Core Principle

Fesa improves how a user's experience is presented without inventing
experience, skills, qualifications, achievements, or employment history.

## Tech Stack

- React
- Vite
- JavaScript
- Cloudflare Workers
- Cloudflare Pages
- IndexedDB
- Gemini API
- PDF.js
- Mammoth.js

## Running Locally

### Install dependencies

npm install

### Start development server

npm run dev

## Environment Variables

Copy `.env.example` to `.env` and configure the required variables.

Never commit `.env` to Git.
